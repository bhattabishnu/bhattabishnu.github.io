# GitHub portfolio starter

A minimal one-page portfolio for GitHub Pages.

## Before publishing

1. Replace every `YOUR-LINKEDIN-USERNAME` in `index.html` with your LinkedIn profile URL.
2. Export your CV as a PDF named exactly `cv.pdf`.
3. Put `cv.pdf` in the same folder as `index.html`.
4. Review the profile and interests text. Adjust any wording that does not accurately represent your experience.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `README.md`, and `cv.pdf` to the repository's top level (not inside another folder).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait a few minutes and visit `https://YOUR-USERNAME.github.io`.
7. If it does not appear, check the Pages deployment status in the repository's **Actions** tab.

## Updating the site

Edit `index.html` in GitHub using the pencil/edit button, or replace it with an updated version. To update your CV, upload a new PDF with the same filename, `cv.pdf`.
